Here are the key fields and their ranges:

weather[0].id — the most useful for mapping images

2xx: Thunderstorm                       // DRAW THUNDERSTORM 
                    
3xx: Drizzle                            // DRAW DRIZZLE
5xx: Rain                               // DRAW RAIN
6xx: Snow                               // DRAW SNOW
7xx: Atmosphere (fog, haze, dust etc.)  // DRAW FOG
800: Clear sky                          // [DONT DRAW OVERLAY]
80x: Clouds 
    801=few,                            // DRAW FEW
    802=scattered,                      // DRAW SCATTERED
    803=broken,                         // DRAW BROKEN
    804=overcast                        // DRAW CLOUDS

main.temp — Fahrenheit if you request imperial, no hard range but practically -60 to 130°F
main.humidity — 0 to 100 (percent)
clouds.all — 0 to 100 (percent coverage)
wind.speed — mph in imperial, 0 to ~200 in extreme cases, typical 0-50
visibility — 0 to 10000 meters (10000 = max/clear)
rain.1h — mm of rain in last hour, 0 to ~50 in extreme cases
weather[0].icon — has a d/n suffix for day/night, useful for switching day vs night images
